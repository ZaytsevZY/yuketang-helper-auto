# 雨课堂助手 Android 0.3.4

原生 Android 客户端，基于主分支 `6eaf8b4` 和旧安卓分支 `31f3f25` 开发。支持雨课堂、荷塘雨课堂、长江雨课堂。最低 Android 6.0（API 23），target/compile SDK 36，无 NDK/ABI 限制，无需安装 Google Play 服务。

## 使用

1. 安装 APK，点击首页“打开雨课堂登录”。在助手的“设置”标签中选择服务器，再在官方网页完成登录。顶栏右侧文字按钮显示“打开助手”或“收起助手”，恢复关闭前的标签。顶栏分两行显示“雨课堂助手”和“安卓-v0.3.4”，版本号随 APK 自动更新，点击标题可返回课堂；左侧循环箭头刷新当前课堂列表或网页。
2. 首次使用默认选择 DeepSeek。在“配置”选择 Moonshot AI、DeepSeek、OpenAI 或 OpenRouter，自动填入 Base URL、文本和视觉模型；所有字段都可继续修改。选择“自定义”可从空白配置开始自行填写。每家服务商及自定义模式的 API Key、Base URL、文本/视觉模型均独立加密自动保存，切换和重启后恢复，并记住上次选择的服务商。输入不完整时也保留草稿；点击“启用当前配置”后用于问答，或点击“启用当前配置并测试”验证。Base URL 支持根地址、`/v1`、完整 `/chat/completions` 及自定义路径。
3. 回到“课堂”刷新并点击正在进行的课堂。应用签到、加载官方课堂网页、同步课件和题目，同时建立原生课堂连接。
4. “题目”逐题查看、AI 分析、修改并提交答案；题目已截止时显示“补答本题”，已作答时可“修改答案并补答”，均需手动确认且保持课堂连接；“AI”直接提问；“课件”翻页、询问当前图片、保存本页 PNG。
5. 在课堂页开启“自动回答”，或者在设置中启用自动分析/自动提交。新解锁题目会进入 AI 队列，校验答案后等待 3 秒自动提交。课堂页与通知均可暂停。初始状态下自动提交关闭。
6. 退出课堂停止后台连接；点击系统返回键退到后台时，已连接课堂会继续由前台服务维护。通知提供暂停与退出入口。

## 实现范围

- Cookie 持久化、网页登录凭据同步、三种服务器独立切换；切换会取消旧课堂任务。
- 主动签到与课件接口、WebSocket 推题、时间线恢复、教师发布新课件、课件晚于解锁事件到达时的待绑定处理。
- 官方网页课件与 WebSocket 消息补充采集。只允许三个准确来源的顶层页面，并校验当前课堂 ID；没有向网页暴露 Key、文件读写或提交命令。
- 断线后指数退避重连，重新签到换取课堂 Token；通知显示当前连接和自动回答状态。
- 每题独立草稿、AI 结果、提交状态；两路并发 AI 请求，忙碌时新题不会因全局 busy 状态丢弃。
- 单选、多选、投票、填空、文字主观题；选项范围、填空数量、解锁与截止校验。未知题型与无法解析的答案不会提交。
- 提交前持久记录状态；响应丢失时不会自动重试，需核对网页后手动解除待核对状态。支持手动调用与桌面端一致的补交接口；只在服务端明确确认本题成功后标记“补答成功”。已结束课堂断开后不能补交，自动回答不会自动补交过期题目。
- 加密文字检测；遇到加密内容必须附带题目所在课件图片，交给视觉模型识别。原生界面不声称解密字体。
- 各服务商整套配置使用 Android Keystore 和 AES-GCM 加密持久保存，重启恢复。旧版单份配置自动迁移；编辑草稿与当前已启用配置独立。清除全部服务商配置或卸载可删除 Key；不备份凭据，不写入日志，不忽略 TLS 错误。
- 可取消的 AI 问答、真实 completion 连接测试、HTTP 错误提示；不依赖供应商实现 `/models`。
- 横竖屏、刘海/系统栏/软键盘避让、可滚动表单、48dp 触控区域、图片缩采样缓存、可选上课常亮。

桌面端的作业/考试详情、网络实验室、CLI 与 CDP 调试工具未移植。本版覆盖手机上课、课堂题目、课件、AI 与自动回答流程。

## 构建与验证

需要 JDK 17 或以上、Android SDK Platform 36。可使用 Android Studio 自带 JDK，在 IDE 中打开本目录。没有强制下载某一家 JDK 的配置。

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
# 模拟器/USB 设备上的流程测试（仅使用本机模拟服务）
./gradlew connectedDebugAndroidTest
```

- 可直接安装的开发 APK：`app/build/outputs/apk/debug/app-debug.apk`
- 正式构建：`app/build/outputs/apk/release/app-release-unsigned.apk`，发布前使用项目自己的长期签名。
- CI：仓库 `.github/workflows/android.yml` 构建 APK 并保留测试/lint 报告，不上传商店或创建 Release。
- 详细验证记录与尚未验证部分见 [TESTING.md](TESTING.md)。真实账号登录、真实课堂协议及指定模型服务需要真实环境验收；模拟服务通过不等于所有学校与机型均已验证。

## 兼容说明

系统 WebView 应保持更新。支持 document-start 的 WebView 会在网页启动时采集课件；旧 WebView 降级为页面启动注入，完全不支持消息监听时仍可使用原生接口，但网页补充采集不可用。官方认证跳转或页面结构变更仍可能需要适配。

Android 13 及以上可授权通知。Android 15 及以上对 dataSync 前台服务有后台时长限制；应用处理系统超时回调并停止课堂，不通过循环重启规避限制。系统省电、网络限制或强行停止应用仍可能中断连接。系统结束进程后不会静默恢复自动提交，需要重新进入课堂。

参考：[Android 前台服务超时](https://developer.android.com/develop/background-work/services/fgs/timeout)、[WebViewCompat 特性检测与来源限制](https://developer.android.com/reference/androidx/webkit/WebViewCompat)、[AGP 9.2 构建要求](https://developer.android.com/build/releases/agp-9-2-0-release-notes)。

## 模型预设

服务商选项与电脑端一致。电脑端会联网发现模型目录；安卓端先填入可修改的默认模型，无需先请求模型列表。模型可用性以所用账号和服务商实际返回为准。

| 选项 | 默认 Base URL | 默认文本 / 视觉模型 |
| --- | --- | --- |
| Moonshot AI（Kimi） | `https://api.moonshot.cn/v1` | `kimi-k3.1-pro` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-5-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-5-mini` |
| 自定义 | 留空，自行填写 | 留空，自行填写 |

默认模型参考 2026-11-14 查阅的官方目录：[Kimi](https://platform.kimi.com/docs/models)、[DeepSeek](https://api-docs.deepseek.com/)、[OpenAI](https://developers.openai.com/api/docs/models/gpt-5-mini)、[OpenRouter](https://openrouter.ai/openai/gpt-5-mini)。预设中的接口地址沿用电脑端配置。

DeepSeek 官方当前要求模型名使用 `deepseek-flash`（实际由 DeepSeek-V4.1-Flash-1017 提供服务）。`deepseek-v4-flash` 是仍接受的旧名称；新配置采用当前名称。已保存的用户配置继续保留，清除配置后恢复 DeepSeek 默认值。

## 手动补答（0.2.1）

保持课堂连接，在“题目”中选中题目，可先让 AI 分析，再核对答案框并点击“补答本题（已截止）”或“修改答案并补答”。未截止题目也提供手动补交入口。弹窗确认后才发送；只有服务端返回的成功列表包含本题 ID 才显示成功。

服务端明确返回课堂 Token 过期码 50004 时重新签到并重试一次；超时、断网或成功列表缺失均不会自动重发。结果不确定时先到网页核对，再点击“我已核对网页，允许手动重试”。是否接受过期或修改答案取决于课堂服务端，不能保证所有学校都允许补答。

## 版本与使用提示（0.2.2）

设置页提供“关于”入口，独立页面显示应用版本、版权信息“版权所有，侵权必究。”、开源许可 MIT，并提示“请按照学校、课堂和老师的相关规定使用本应用，不得用于课堂或考试作弊。”该区域不显示作者或仓库信息。

## 浅色玻璃界面（0.3.0）

采用 A（Kyant0 AndroidLiquidGlass / Backdrop）的视觉方向，使用原生 View 实现：顶栏、底部图标导航、按钮、下拉选择器和开关区域采用浅色玻璃质感、圆角与触摸反馈；题目、问答、说明和输入框保持浅色实底及深色文字。六个主要入口位于底部，“关于”仍从设置进入。

本版没有引入 Compose / Backdrop 依赖，也不对网页或正文进行实时模糊采样。Android 13 及以上硬件渲染时使用 RuntimeShader 对装饰色场做边缘折射；较旧系统、软件绘制或着色器失败时使用浅色渐变和高光边缘降级。没有持续动画循环、截图采样或每帧位图分配。最低系统要求仍为 Android 6.0。

## 新题目提醒（0.3.1）

进入并连接课堂后，默认对实时新题目发送系统横幅通知：标题为“某某课堂发布了一个问题”，正文为“时限 60 秒”或“未定时限”。提醒不依赖 AI 配置，也不依赖助手页面处于前台；课件尚未加载时也可收到提醒。点击通知打开对应题目；若已断开该课堂或题目未同步，则回到课堂页并提示，不自动进入其他课堂。

在“设置 → 新题目弹窗提醒”调整开关后立即保存并生效，重启后保留。关闭提醒或退出课堂会清理题目通知，课堂连接常驻通知保持独立。重复推送按服务器、课堂和题目去重，最近 500 条记录跨重启保存；历史时间线恢复不弹窗，关闭期间收到的题目在重新打开提醒后不补弹。

Android 13+ 进入课堂时申请通知权限；设置中提供“系统通知设置”入口。Android 8+ 使用独立的高重要性“新题目提醒”通知渠道，较旧系统使用高优先级通知。能否显示横幅、声音和振动仍受系统授权、通知渠道、勿扰模式及厂商策略控制，不申请悬浮窗或全屏打断权限。[Android 官方通知说明](https://developer.android.com/design/ui/mobile/guides/home-screen/notifications)。

API Key 输入时自动加密保存；点击“启用当前配置”会再次保存整套配置并启用，显示“当前配置已保存并启用”。点击“启用当前配置并测试”也是先保存再测试，即使测试失败，已保存配置仍保留。

## 后台运行引导与配置提醒（0.3.2）

“设置 → 后台运行设置”提供本应用系统详情、电池优化列表两个入口；标准页面不可用时回退到应用详情或系统设置。页面显示系统电池优化豁免、后台活动限制及省电模式状态，从系统设置返回后刷新。手机厂商的自启动、后台锁定状态无法通过这些标准接口判断，需要用户手动核对。

页面说明如何允许后台活动、选择“不优化 / 无限制”，以及在多任务界面通过下拉、长按或菜单锁定应用卡片；上滑卡片通常表示结束应用。已有“上课期间保持屏幕常亮”只负责屏幕亮度状态，与后台运行设置分别处理。应用不会自动改变系统策略，不申请直接豁免弹窗、无障碍或后台任务锁定权限，也不承诺永久保活。

未启用包含 API Key、接口地址和模型名称的配置时，底部“配置”入口右上角显示红色小圆点，并提供无障碍说明。填写草稿后仍保留提醒，点击启用后消失；重启恢复，清除已保存配置后重新显示。

依据：2026-11-14 核对的 [Android 电池优化设置接口](https://developer.android.com/reference/android/provider/Settings#ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS)、[Android 后台省电机制](https://developer.android.com/training/monitoring-device-state/doze-standby)、[华为后台运行说明](https://consumer.huawei.com/cn/support/content/zh-cn00428704/)、[小米 Powerkeeper 说明](https://dev.mi.com/distribute/doc/details?pId=1628)。厂商说明中的路径和手势不代表所有系统版本都一致。

## 设置自动保存（0.3.3）

设置页所有开关调整后立即保存并生效，移除“保存设置”按钮。修改单项时读取最新配置，只更新该字段；后台状态刷新和通知栏暂停操作会同步现有控件，保留设置页滚动位置。服务器选择原本即为即时保存；系统电池、后台权限仍在手机系统设置中由系统管理。

## 微信快捷登录说明

2026-11-14 核对官网实现：登录首页的“微信快捷登录”提示针对微信桌面端，授权页面使用网站扫码/快捷登录流程。不能仅给安卓助手增加一个权限就让这一入口变成手机微信授权登录。手机可尝试官网已有的账号登录或扫码登录入口；本应用未实现雨课堂官方支持的原生手机微信一键授权，真实账号登录仍待验收。

## 签到请求兼容修复（0.3.4）

真实测试课堂定位到签到请求缺少官网当前使用的 `source: 5`，服务端返回 HTTP 400 / code 50400，导致原生课堂不断重连，无法通过作答连接检查。现已补齐，且不改变大整数课堂 ID 的字符串表示。真实测试课堂已成功连接，手动提交测试答案 A 后，重新查询官网课件接口返回对应题目 `result: ["A"]`。

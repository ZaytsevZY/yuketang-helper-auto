# ADR 0005：日志策略

- 状态：已接受
- 日期：2026-08-30

## 决策

应用日志采用结构化记录并区分组件、级别、时间与关联 ID。所有持久化或导出路径统一经过脱敏器；Cookie、Authorization、Token、API Key 和大体积响应正文默认不记录。

CLI stdout 保留给稳定 JSON/JSONL 数据，日志与错误写 stderr。网络原始记录具有单条与总容量上限，默认只存脱敏元数据。

## 影响

M0 只建立 CLI 输出纪律；日志实现、redactor、容量控制和敏感数据扫描随 M2/M5 落地，避免在尚无真实数据源时提前设计复杂日志框架。

# 网络实验室：Web 探测

入口：底部「网络实验室 → Web 探测」。先在左侧登录雨课堂并打开目标页面，再点击「分析当前页面」。不需要开启深度捕获。

## 使用流程

1. **发现脚本**：读取当前页面的 `document.scripts` 和 Resource Timing 中实际加载的脚本，使用当前版本的 URL 下载。已经加载但移除 script 标签的懒加载 chunk 也能发现。第三方非雨课堂域名的 SDK 会跳过。
2. **查看路由与接口**：「路由」还原嵌套 `children`、相对路径、名称和路径参数；「接口」提取请求对象和方法调用中的路径、method、显式参数名；「路径」保留其他字符串和拼接模板线索。点击条目查看源码片段、原始行列和字符偏移。
3. **跟进懒加载代码**：「脚本」列出静态 `import()` 和可还原的 Webpack chunk 映射。待分析脚本可逐个点击「分析」；它们不会全部自动下载。也可在左侧正常访问详情页后重新分析，使 Resource Timing 补充实际加载的 chunk。
4. **反查调用点**：输入接口名、字段名或函数名后点击「搜索源码」。搜索遍历本次已下载的所有脚本，最多返回 100 处上下文；不会执行搜索结果中的代码。
5. **验证接口**：选择接口候选，点击「填入 GET 地址」，填写占位符与查询参数，再点「GET 探测」。默认 `XTBZ: ykt`，可修改；Cookie 由左侧浏览器会话提供，Authorization 仅从同一页面的登录态读取。「已捕获」也可选取已有 GET 请求。不同参数的响应保留在「响应」中，可切换对比。
6. **保留证据**：「导出报告」保存 JSON，包括页面 URL、分析时间、脚本 URL/SHA-256、候选和源码位置、已有网络请求、最近 20 次探测结果及分析失败/截断信息。HTTP 状态与业务错误正文均原样表达，不将 HTTP 200 自动当作业务成功。

## 判读范围

本功能采用 OneTHU《雨课堂接口逆向方法论》的“当前页面 → bundle → 路由/接口线索 → 手动验证”流程。文档中的版本、路由、字段含义只作为历史案例，不作为新接口的默认规则。尤其不能仅凭字符串 `/subject` 判断学生可访问，也不能凭作答数量推断考试已交卷。

静态结果均为**候选**，与「已捕获」请求分别展示。常量前缀、模板和受支持的拼接可恢复；无法求值的变量保留 `{变量}`。运行时生成的路由、复杂表达式、远程配置、未加载/未分析的 chunk 可能缺失。`path` 属性与 HTTP 方法调用也可能来自通用库，需结合源码和实际页面交叉验证。只有直接出现的参数键会被提取，不猜测必填性或业务含义。已有请求可能来自同源其他标签页，不表示候选已获权限验证。

Webpack 解析只静态解释字面量、字符串拼接和 chunk 名称/hash 映射；不执行下载的 JavaScript。源码片段会尝试按 token 换行，行列和 offset 始终对应原始文件。无法解析时显示错误并继续其他脚本。

## 边界与资源限制

- 静态下载限雨课堂 HTTPS 域名、默认端口，无 Cookie/Authorization。重定向逐跳校验，最多 3 次。
- GET 探测只允许分析页面同源，复用登录态；不自动遍历接口，不开放 POST/PUT/DELETE，不跟随接口重定向。更换页面后需重新分析。
- Web 探测报告始终走凭据脱敏，与 DEBUG 网络记录模式独立；仍可能包含作业、课程等个人业务数据。
- 自动分析最多 12 个已加载脚本，清单最多 500 个，其余按需分析。单脚本最多 8 MiB、源码缓存共 32 MiB；重新分析页面替换当前缓存。
- 下载和 GET 请求超时 15 秒；脚本解析在独立 worker 内运行，20 秒超时。可以点击「停止」，已完成的条目仍保留。
- GET 响应最多 64 KiB，超出标记为截断。报告最多 15000 条候选；脚本/候选上限及失败会记录在分析提示中。

核心模块：`apps/desktop/main/web-source-analysis.ts`（静态解析）、`web-probe-controller.ts`（采集/探测/报告）、`electron-web-probe.ts`（浏览器适配和 worker）、`renderer/src/components/WebProbePanel.vue`（界面）。正式发行包包含独立解析 worker。

回归验证：`npx vitest run tests/contract/web-probe.test.ts`。

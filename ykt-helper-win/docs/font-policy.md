# 字体与雨课堂加密内容规范

本规范适用于桌面助手及同仓库浏览器插件的后续开发。依据用户提供的《雨课堂加密字体技术文档》，并以 CSS 标准澄清字体回退及加载检测的边界。文档中示例字体名和文件名不是可直接使用的线上资源。

## 当前审计结论

- 未发现 `font-family: "YktEncrypted", inherit` 或将 `initial`、`unset`、`revert`、`revert-layer` 混入字体列表的写法。现有单独的 `font-family: inherit` 合法，保留。
- 作业详情现已按 OneTHU PR #32 接入加密字体和隔离正文渲染，加载、缓存与失败回退见 [作业详情说明](assignment-detail.md)。已交卷、有批改分数且官网开放查看的考试，通过已验证的考试结果接口复用同一隔离渲染及 `show_paper.data.font` 字体路径；其余考试只读取封面。
- 课堂适配器 `packages/routing/src/active/host-adapter.ts` 将题干、选项作为普通字符串处理；助手面板及旧插件也按普通文本展示。AI 服务会使用这些字符串。新的作业详情有独立契约，不把加密原文加入现有 AI 题目上下文；课堂和旧插件不能据此宣称支持加密题干。
- 当前 PDF 导出以课件图片为内容。截图中的字形和 DOM 中的字符是两回事；不得由图片导出正常推断文本导出正常。

共享字体栈和静态检查适用于所有后续开发。作业详情使用 PR 确认的 `data.font` 字段，以下要求继续作为新增接口和其他渲染路径的约束，不猜测或拼接 `exam_font_*.ttf` 地址。

## 字体声明

桌面助手的默认字体栈定义在 `apps/desktop/renderer/src/fonts.css` 的 `--ykt-font-body`。需要与正文一致的回退字体时复用它，避免多处维护不同列表。

```css
/* 示例：仅在当前内容的字体已经注册且加载成功后启用。 */
.encrypted-content-scope .xuetangx-com-encrypted-font {
  font-family: 'YktEncrypted_content_version', var(--ykt-font-body);
}
```

禁止把 CSS 全局关键字写进字体列表。`font-family: inherit` 是合法的完整属性值；`"inherit", sans-serif` 也是合法的真实字体名列表，但通常没有实际用途。不得用简单的关键字搜索禁止这些合法值。[CSS Fonts 字体名语法](https://drafts.csswg.org/css-fonts-4/#font-family-prop)

不同内容、版本、字体 URL 必须使用不同字体族和局部作用域。不能用全局 `.xuetangx-com-encrypted-font` 配合单个可变 `YktEncrypted` 字体覆盖多个页面。只对明确标记的加密片段应用字体，不覆盖普通文字和图标。`@font-face` 使用 `font-display: swap`，允许非加密内容先显示；这不保证置换字符在字体未就绪时可读。

`npm run font-policy` 已接入 `npm run lint`。它检查桌面端、共享包和存在时的同仓库旧插件源文件，覆盖 CSS 声明、HTML 内联样式、Vue 样式块和 JS/TS 中常见的字体属性、赋值、`setProperty` 及模板字符串。它是静态检查，不执行代码、不解析外部样式表，不能证明动态变量、CSS 自定义属性替换或远端内容最终有效；动态字体必须通过下面的运行时验收。

## 新接口接入与资源加载

1. 从同一真实响应中确认加密正文、标记及与之绑定的字体 URL，保留内容 ID、版本、来源和字体信息。不要先丢掉 HTML 标记或字体元数据再交给普通文本 DTO。禁止把加密原文标为已解码文本。
2. 字体读取走桌面主进程的受控资源通道，复用雨课堂浏览器会话。按提供文档设置 `Referer: https://pro.yuketang.cn/`，保留正常浏览器 User-Agent；不得伪造身份或要求用户复制 Cookie。Cookie 仅按会话域规则发送，不能手工复制给外部域。校验 HTTPS、允许的雨课堂/学堂在线来源与每次重定向目标。
3. 下载有超时、大小上限并可取消。验证 HTTP 成功、响应大小、MIME 与二进制魔数，拒绝 HTML 登录页、JSON 错误和空响应，不能仅按 `.ttf` 后缀判断。支持的格式明确列出：TTF `00 01 00 00`、OTF `OTTO`、WOFF `wOFF`、WOFF2 `wOF2`；魔数只作初筛，实际字体解析也必须成功。
4. 将验证后的资源注册为当前内容独有的 `FontFace` 或 `@font-face`，资源 URL 及 CSS 字体族不能由未转义的远端文本拼接。主进程、IPC 和 Renderer 继续遵守现有依赖边界。HTML 展示仍须清洗，不能为字体支持绕过 `simple-markdown.ts` 的转义或注入远端脚本。
5. CSP、跨源访问和资源生命周期随实际资源通道设计；只开放所需字体来源，不宽泛关闭 CSP。字体、Blob URL、样式及内容离开作用域时正确释放，避免跨账号或跨试卷残留。

## 加载检测、失败与缓存

- 必须检测“字体已注册并加载成功”和“当前片段选择了正确字体族”两件事。使用 `document.fonts.load` 时传入实际加密片段的非空样本文本，检查结果非空、包含预期字体且其状态为 `loaded`。默认样本是空格，`unicode-range` 可能导致没有匹配字体；Promise resolve 也不证明元素实际用了它。[CSS Font Loading 匹配与加载规则](https://drafts.csswg.org/css-font-loading-3/#font-face-set-load)
- 解析 `getComputedStyle(element).fontFamily` 的字体列表，按完整名字比较首选字体；不要依赖引号序列化形式，也不要用 `includes` 做子串匹配。计算样式仍不能独立证明每个字形可用，应使用已知样本做视觉验收。文字宽度对比可辅助诊断，但等宽字形可能宽度一致，不能作为唯一成功或失败条件。
- 同一字体 URL 复用同一进行中的请求。失败时释放或重建失败 Promise，允许至多一次绕过缓存的强制重试，然后降级；不可递归重试或让页面无限等待。
- 成功缓存以完整 URL 为键，保留查询参数中的版本/哈希；隔离账号及环境，缓存有效期最长 7 天。失败退避 10 分钟，显式强制重试最多突破一次。磁盘缓存记录二进制、MIME、写入时间，读取时重新校验；登录页或损坏数据不进入成功缓存。
- 失败后保留其他可用功能，提供官方页面入口或已经可读的截图。去掉字体类只能保留原始字符，**不能还原明文**，不得把这种状态标记为成功解码。技术原因写入注释及脱敏日志，UI 仅在必要时给出简短状态和操作。

## AI、复制与导出

字体替换只改变字形，不改变 Unicode。即使画面可读，`textContent`、`innerText`、原始 HTML、剪贴板纯文本、JSON 和发给模型的字符串仍可能是置换字符。

接入加密内容时，必须让契约区分原始加密文本、视觉渲染结果和已验证的可读文本。AI/翻译/复制/纯文本导出不得直接使用加密原文充当明文；可采用已正确渲染的图像输入或用户授权的 OCR，并标明识别来源和失败状态。不得编造字符映射，也不能仅靠移除 HTML 标签完成所谓解密。图像/PDF 渲染须等对应字体成功加载后捕获，失败时明确降级。

## 接入验收

新增加密题干展示或文本使用路径，至少验证：

- 一份真实加密内容与官方页面显示一致，题干、选项中的加密和普通片段混排正常。
- 同时打开两份不同字体的内容、更新同一内容的字体版本时互不污染。
- 首次下载、有效缓存、过期缓存、损坏缓存、404、登录 HTML、超时及字体解析失败均有确定结果；强制重试和退避次数符合约束。
- 多消费者共享下载；关闭内容、退出账号、切换环境后不会泄漏旧状态。
- AI、翻译、复制、导出不会把原始置换字符当作已还原明文；字体失败不导致白屏或无限等待。
- `npm run font-policy`、相关回归测试和构建通过。静态检查通过不替代上述真实样本验收。

字体及教学内容仅用于用户获授权的个人学习与阅读；不批量转存或对外分发字体和内容，其权利仍归原权利人。此声明留在开发文档中，无需在业务界面添加技术说明。

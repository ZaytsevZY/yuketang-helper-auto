# 笔记模式实现计划

状态：待实现。更新日期：2026-09-30。

本计划面向 `ykt-helper-win` 桌面客户端，在现有多页面标签栏中增加独立的本地笔记标签页。选中笔记标签时，中央工作区显示笔记编辑器；课程网页保留在原标签中。笔记以课件图片为底图，支持手写标注、文本框和逐页文字笔记，并在本地自动保存。后续通过 PDF 和 PPTX 导出，将课堂记录用于复习或在 PowerPoint 中继续编辑。

本文是开发计划，不代表功能已经发布。文中的新增文件、接口、命令和性能数值均为拟定设计或验收目标；现有代码位置使用链接标明。浏览器 userscript `ykt-helper` 的适配不在本轮范围内。

## 目标与交付边界

首个可发布版本完成 N0 至 N4：本地笔记标签、手动翻页、标注、逐页笔记、可靠保存与恢复。N5 交付课堂跟随；N6 交付 PDF 与 PPTX 导出。N5 的真实协议验证可在 N0 提前开展，但不阻塞手动笔记版本。网页与笔记并排查看作为后续增强，不列入首版验收。

- 用户可从当前课件直接进入笔记模式，查看大幅 slide，而非在现有 380px 助手栏中书写。
- 提供选择、画笔、荧光笔、文本框、箭头、矩形、整对象橡皮擦、撤销和重做；文字笔记首版使用纯文本多行编辑。
- 已保存笔记跨重启恢复，按账号、环境、课堂、课件和页面隔离；课件缓存清理不删除笔记。
- 原始 slide 保持图片形式，新增文字和形状可编辑。首版不重建原 PPT 对象、不编辑原课件文字，也不实现 PPTX 导入或外部编辑回写。
- 笔记默认仅存本地，不自动发送到 AI 服务；原有 OCR、翻译和提问可继续使用所选课件页。
- 第一轮不加入云同步、多人协作、完整 Office 编辑器、富文本备注、手写识别或无限画布。

### 承载方式决策

采用“标签级独立，本地组件渲染”的方案。用户看到课程网页和笔记两个并列标签；工程上复用现有本地 Vue Renderer 显示笔记，不为每个笔记新建远程网页、localhost 服务或带独立 preload 的 WebContentsView。主容器只负责根据当前标签显示正确内容，不拥有一个跨所有课程的全局笔记模式。

| 方案                     | 交互与工程影响                                                                         | 决策                 |
| ------------------------ | -------------------------------------------------------------------------------------- | -------------------- |
| 全局开关替换中央内容     | 切换简单，但在多课程之间容易不清楚当前笔记归属；浏览器刷新、返回和地址栏的目标也会混淆 | 不作为主导航模型     |
| 新增普通 web 网页标签    | 标签语义明确，但需要额外的加载、桥接和窗口生命周期管理                                 | 首版无需新增网页实例 |
| 本地笔记标签复用中央区域 | 每份课件有清晰入口、页码与保存状态，同时复用已有 Vue 与 IPC 能力                       | 本轮采用             |

此决策替代此前的全局 `WorkspaceMode` 开关方案。首版仍可从课件页一键进入笔记，但该动作的含义是打开或激活笔记标签。

## 界面与交互

### 标签与进入路径

顶部标签栏同时容纳“网页”和“笔记”两种条目。网页保留站点图标；笔记使用文档图标与“笔记 · 课件名”，悬停可读课程、课件及环境。首次打开时放在来源网页旁，后续不自动调整顺序。不同账号、环境或课件同名时在标签辅助文字中区分。

- 主要入口：课件面板“记笔记”；当前课件页已知时直接打开该页，未知时提示选择课件，不猜测网页当前 slide。
- 复习入口：课件面板“我的笔记”列出本地已保存课件，可离线打开。普通“+”仍新建网页，不改变用户已有习惯。
- 每个账号、环境、课堂和课件组合最多打开一个笔记标签；笔记标签身份不包含 slideId。重复点击“记笔记”复用已有标签，避免多个编辑器同时修改同一课件。
- 普通标签切回恢复原页、缩放、平移、工具、笔记滚动位置和光标；显式从另一页点击“记笔记”才定位到指定页，并先提交旧页的编辑操作。
- 打开另一份课件创建或激活另一笔记标签，不将当前编辑器静默改绑。尚未保存的草稿属于笔记文档状态，不属于组件挂载状态。
- 浏览网页、回到来源网页和打开笔记均不自动重新连接课程，也不调用会 reload 的连接路径。
- Ctrl+Tab / Ctrl+Shift+Tab 按标签栏顺序切换网页和笔记；Ctrl/Cmd+W 关闭当前工作区标签并走保存流程，不能绕过为笔记定义的关闭检查。首版无需标签拖出新窗口。

### 工作区布局

以下示意中的课件与页码仅用于说明布局。

```text
标签栏   [课程 A 网页] [笔记 · 第三讲 ×] [课程 B 网页] [+]
上下文   第三讲 / 本地笔记       [返回课程网页] [已保存] [导出]
工具栏   选择  画笔  荧光笔  文本  箭头  矩形  橡皮  撤销  查看原图
         ┌────────┬─────────────────────────┬─────────────┐
         │页缩略图│                         │ 本页笔记    │
         │全部/有笔记│      slide + 标注       │ 文字编辑器  │
         │  1  2  │                         │             │
         └────────┴─────────────────────────┴─────────────┘
状态栏   第 12 / 40 页   100%   适应窗口   自由浏览   老师第 15 页
```

笔记标签被选中时，原地址栏位置显示课件上下文和本地保存状态，不伪装成雨课堂 URL。网页的返回、前进、刷新和环境切换控件不作用于笔记；保留明确的“返回课程网页”按钮。标签与文档工具分层，避免再出现一套全局“网页 / 笔记”开关。

默认展示缩略图、中央画布和本页文字笔记；全局 AI 助手默认折叠。用户打开 AI 时，右侧区域切换为“本页笔记 / AI”两项，共用一块空间，避免同时叠出两个宽侧栏。切换这些面板保留未完成输入。笔记标签使用自己的侧栏偏好，返回网页时恢复网页原有布局；网络实验室仅按用户操作展开。

自适应依据中央工作区可用宽度：首版拟在宽度小于 1100px 时折叠缩略图，小于 900px 时让文字笔记通过抽屉打开；不自动进入分屏。阈值在 N0 样例验证后调整。沿用现有白绿样式与字体规范，工具按钮至少 32px，触控场景提供 40px 点击区域，折叠不删除内容。

### 页导航与编辑规则

1. 缩略图单击翻页，标明当前页和“有笔记”，支持“全部 / 有笔记”筛选；笔记缩略图不复用 AI 的 Ctrl 多选语义。页码输入支持跳页，错误页码保留原页并提示。
2. 原 slide 为不可选中的底图层。选择工具可选中和移动标注；画笔与荧光笔连续使用；文本、箭头和矩形完成一次创建后回到选择工具。橡皮擦按对象删除并可撤销，不改变底图。
3. “查看原图”只隐藏标注并临时停止编辑，保留笔记侧栏和数据；按钮显示“恢复标注”。退出查看原图后恢复此前工具，不能在隐藏图层上产生不可见笔画。
4. 画布支持适应窗口和以指针为中心缩放。普通滚轮用于平移或滚动，不在单页画布上触底自动翻页；翻页由按钮、缩略图或画布获得焦点后的 PageUp/PageDown 完成。
5. 文本框双击编辑；Esc 结束编辑回到选择工具。空白且未提交的文本框可取消，已有文本不因 Esc 静默回退。Delete 仅删除选中的标注，输入框中保持原生文字删除。
6. Ctrl/Cmd+Z 在文字编辑时使用文字编辑历史，画布焦点下使用当前页图形历史；Ctrl/Cmd+S 刷新保存队列。所有单键绘图快捷键在输入框、中文组合输入和弹窗中停用。
7. 左侧页列表保留键盘焦点和可读页名，画布工具提供文字标签和可见焦点；保存状态以文本说明，并用非打断式状态通知告知辅助技术。

### 标签切换与保存反馈

| 用户操作           | 确定行为                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| 切到网页或其他笔记 | 结束当前输入/笔画并入队保存，允许立即切换；原笔记文档继续后台保存，失败在其标签显示文字提示                  |
| 关闭笔记标签       | 已保存直接关闭；有待保存内容先显示“保存中”并等待，失败则保留标签，提供重试、导出草稿、放弃未保存改动         |
| 关闭来源网页       | 笔记保持打开；若该网页承担课堂事件连接，先明确提示关闭会停止跟随。确认关闭后笔记转自由浏览                   |
| 返回课程网页       | 来源标签仍在对应课堂时仅激活，不刷新；来源已关闭或已导航离开时，明确提供“重新打开课堂”，不擅自重新签到或连接 |
| 重启后打开笔记     | 首版从“我的笔记”恢复最近保存页和缩放；不自动进入课堂或开启跟随，不承诺重开全部标签                           |
| 切换账号或环境     | 标签的文档身份不变；账号实际变更时先完成旧上下文保存或保留隔离草稿，再锁定旧账号笔记编辑，显示身份不匹配提示 |

标签保存状态仅表示当前已编辑内容是否落盘：未保存、保存中、已保存、保存失败。必须收到对应内容版本的持久化响应后才能显示已保存；失败提示持续存在，不能只闪现 toast。底图准备进度另显示“图片离线准备中 / 可离线查看 / 图片未缓存”，不能把文字保存成功等同于整份课件离线就绪。

关闭笔记表示关闭视图，不删除笔记。关闭活动笔记后优先回到仍有效的来源网页，否则激活相邻工作区标签；关闭后台笔记不改变前台。若笔记仍在前台而最后一个网页被关闭，BrowserController 自动创建的空白网页必须留在后台。首版不提供一键清空整份课件；删除选中标注可撤销。正常退出需要等待所有笔记文档的保存队列，不能只保存前台标签。

### 课堂跟随与提醒

默认自由浏览，老师页码与正在编辑的页码分别显示。“跳到老师页”是一次性跳转，“跟随老师”才启用持续跟随，两者不能混为一个操作。

| 当前状态与触发                     | 下一状态与反馈                                         |
| ---------------------------------- | ------------------------------------------------------ |
| 自由浏览时老师翻页                 | 只更新“老师第 N 页”，不改变画布                        |
| 开启跟随且没有编辑操作             | 切到老师页，保持适应窗口策略                           |
| 跟随中开始画笔、输入文字或手动翻页 | 立即暂停跟随，保留当前页，显示“正在记笔记，已暂停跟随” |
| 用户停止输入                       | 继续保持暂停；不通过超时自动恢复跟随                   |
| 切到其他标签                       | 原笔记暂停跟随，后台只更新老师页快照；返回时可主动恢复 |
| 断线、课堂结束或来源网页关闭       | 停止跟随并说明原因；重连后不自动夺取当前页             |

通知新题时显示与对应课堂关联的轻提示和“去课堂”动作，不自动抢占笔记焦点或跳到题目页。用户点击后完成当前编辑并保存，再激活相应课程网页。多份笔记可同时打开，但只有与当前已连接课堂对应、且有真实翻页事件的文档可跟随，不为每个笔记隐式建立独立课程连接。

### AI 上下文与后续分屏

笔记中的“提问本页”默认只引用当前原 slide，发送前显示课件名和页码。附带文字笔记或带标注截图必须由用户主动勾选并预览。原有“截图当前网页”在笔记标签内应禁用或改为明确选择来源网页；严禁后台截取最近活动网页却标成当前笔记。AI 回复不自动写入或覆盖笔记。

后续可增加“与课堂并排”，初始比例为网页 40%、笔记 60%，允许调整并一键返回独立笔记标签。网页自身页码与笔记浏览页默认独立，不双向驱动。窄屏退出分屏前保留两侧状态。此模式需单独验证 Electron 原生视图边界、焦点、弹窗遮挡和课堂提醒，首版不实现。

现有 [PRODUCT.md](../apps/desktop/PRODUCT.md) 和 [DESIGN.md](../apps/desktop/DESIGN.md) 规定网页始终占据中央区域。N1 应同步调整为“课程网页是默认标签；中央区域展示当前网页或本地笔记标签”，并记录上述侧栏及窄屏规则。

## 技术方案

### 画布和导出选型

拟采用 `konva` 与 `vue-konva` 实现标注交互，业务数据独立于 Konva 节点树。N0 验证 Vue 3 兼容性、中文文本输入、坐标变换和依赖许可证后锁定版本；新增依赖只在实施阶段写入 package.json 与 lockfile。

PPTX 使用 `pptxgenjs` 在桌面主进程生成。PPTist 保留为未来完整演示文稿编辑需求的候选，首版不引入其应用框架。此前调研确认 PPTist 当前采用 AGPL-3.0，本轮选型无需依赖其代码。

参考依据：Konva 官方推荐在 Vue 中[保存业务状态](https://konvajs.org/docs/vue/Save-Load.html)；[PptxGenJS](https://github.com/gitbrent/PptxGenJS)支持图片、文字和形状生成，并提供[演讲者备注接口](https://gitbrent.github.io/PptxGenJS/docs/speaker-notes/)；[PPTist 项目说明](https://github.com/pipipi-pikachu/PPTist/blob/master/README_zh.md)列出了其编辑能力和许可证。以上能力不代表本项目已经完成适配。

### 工作区与原生网页生命周期

新增 `packages/contracts/src/workspace.ts` 与主进程 `workspace-controller.ts`。WorkspaceState 保存有序的 WorkspaceTab 列表和 activeWorkspaceTabId；WorkspaceTab 使用 `kind: 'web' | 'notes'` 判别。网页条目引用 browserTabId，笔记条目包含账号/环境/课堂/课件组合、可选 sourceBrowserTabId 和标题。来源网页关联可失效，不能作为笔记持久化主键。

新增类型化 `getWorkspaceState`、`openNotesTab`、`activateWorkspaceTab`、`closeWorkspaceTab` 和变更订阅。主进程管理标签身份与激活，Renderer 管理按文档隔离的页码、缩放、草稿、历史和保存队列；服务重启后由已持久化笔记恢复。关闭与退出采用 flush 完成确认，主进程等待确认后移除笔记条目，不由标签删除事件直接卸载草稿。

BrowserController 继续管理远程网页实例和导航；WorkspaceController 协调其显隐。选中笔记时隐藏当前原生网页视图，将焦点交给本地 Renderer；原网页的登录会话、课堂连接与网络观察器继续存在。网页可见条件统一为“活动工作区条目是对应 web 标签且布局宽高大于零”。不要把零尺寸当作标签身份，也不要仅靠 CSS 或 z-index 遮挡原生视图。[Electron 官方文档](https://www.electronjs.org/docs/latest/api/web-contents-view)说明 WebContentsView 承载 WebContents；本项目已经通过主进程管理其边界，本轮沿用此架构。

所有网页新建、激活、关闭、自动入课和 IPC/CLI 导航入口需经过工作区协调；resize 只更新几何信息，不能改变活动标签。关闭非活动来源网页不应激活其他网页遮住笔记。现有 BrowserController 的 `openLesson` 会对已有课堂执行 reload，因此“返回课程网页”必须使用纯 activate 路径。切换 workspace 与 browser 状态使用有序更新，避免后台 load 事件抢走活动标签。

BrowserState 暂保留现有远程浏览器含义并标明最后选中网页，不将笔记伪装成带雨课堂 URL 的 BrowserTabState；GUI 展示依据 WorkspaceState。新增 workspace CLI 命令镜像本地标签操作。原有显式 browser activate/open 命令激活网页工作区；在笔记前台执行无目标的 browser reload/back/capture 等操作应返回明确错误，禁止静默操作隐藏网页。检查 `cli-desktop-controls.ts`、AI 截图、web probe 以及依赖 `browser.webContents` 的调用点，资源下载等无导航操作仍可使用稳定 session。

`AssistantPanel.vue` 中的课件目录和加载状态抽到 `renderer/src/courseware-state.ts`；笔记选择状态按 NoteDocumentKey 隔离。活动笔记将其课件与 viewingSlideId 显式传给助手，teacherSlideId 和 AI 多选集合保持独立。AI 选择不能隐式重置笔记页面，另一网页的环境事件也不能重新绑定已打开的笔记。第一版不将自主翻页反向驱动官方网页。

仅挂载活动笔记的画布；非活动标签保留轻量文档状态和待保存队列，可释放解码图片。组件卸载前终结未完成操作，之后仍由文档状态管理器执行保存；不能依赖整个编辑器永远 KeepAlive 才避免丢数据。

### 笔记数据与存储

在 `packages/contracts/src/notes.ts` 新增以下概念，并从 contracts 入口导出：

| 数据               | 拟定字段与语义                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| NoteScope          | environment、userId、lessonId、presentationId、slideId，均参与唯一键                                           |
| SlideNote          | schemaVersion、scope、revision、canvasWidth、canvasHeight、sourceFingerprint、annotations、bodyText、updatedAt |
| Annotation         | 稳定 id、判别字段 kind、坐标和样式；kind 为 pen、highlighter、text、arrow、rect                                |
| SaveSlideNoteInput | scope、expectedRevision、mutationId、完整可编辑内容快照                                                        |
| NoteSummary        | 页面标识、是否有标注或正文、updatedAt，供缩略图显示                                                            |

所有图形坐标、线宽和字号均存储在固定课件坐标系中，视口缩放、平移和设备像素比仅影响显示。优先采用 Presentation 的有效尺寸；缺失时以成功解码的图片尺寸初始化并持久化。后续窗口缩放不改变保存坐标。同 ID 底图发生变化时保留旧版本和笔记，提示用户确认适配，不自动覆盖或拉伸旧标注。

使用独立 `slide_notes` 表，以五元 scope 为复合主键；正文和对象 JSON 原样保存，不复用日志脱敏函数。通过专用 NoteStore 提供读取、按课件列摘要和条件保存，SQLite 与内存实现遵守同一契约。表结构升级使用版本化迁移，并保留旧数据库兼容性。

保存采用事务内 revision 比较并递增；创建使用 expectedRevision 为 0。mutationId 用于识别提交成功但响应丢失后的重试，重复请求不能重复递增 revision。冲突返回现存 revision，保留本地草稿，提供重新加载或导出草稿，禁止静默覆盖。数据库已有更新 schemaVersion 时拒绝降级写入。

笔记表不进入课件 TTL、LRU 或“清理缓存”的删除范围，重置设置也不清笔记。笔记导出是独立显式操作，不随网络诊断导出带出正文。Backend 校验 scope 与当前已识别账号的关系；离线仅允许访问此前确认过的本地身份，不创建匿名公共笔记空间。

### 自动保存与退出

Renderer 以页面为单位管理 dirty 状态、撤销栈和保存队列，文本变更防抖目标为 500ms，笔画和拖动在一次操作完成后入队。同页请求串行，不同页独立；每次请求捕获完整 scope 和内容版本，旧请求回包不能清除新编辑的 dirty 状态。

翻页、切换笔记标签和窗口失焦时刷新待保存队列；切换可立即完成，原文档状态继续持有保存任务。关闭标签需要等其保存完成；正常退出先拦截 close，完成所有笔记文档的 Renderer flush 与主进程写入后再执行现有资源销毁，不能提前调用 `destroy` 和 `cleanupServices`。保存失败时保留草稿，允许重试、导出恢复文件或明确放弃后退出。

强制终止只能保证恢复最近一次成功提交的数据，界面和文档不承诺零丢失。撤销/重做按页面和课件隔离，撤销本身也会触发保存；首版不持久化撤销历史。

### 图片资源与离线恢复

笔记关联的底图需要独立持久副本，不能只引用会过期的远程 URL 或可被淘汰的普通图片缓存。主进程利用现有登录 session 获取图片，经类型、大小和解码校验后按内容哈希保存到笔记资源目录，数据库记录账号范围内的关联关系与尺寸。

Renderer 按 slide 标识通过受限接口取资源，不接受任意文件路径。复用现有图片下载能力时补充目标校验与重定向检查；不将 Cookie 或 Token 传给 Renderer。画布使用本地受控资源，避免跨域 canvas 导出失败。

首次保存可先提交笔记内容，再异步准备底图；两者分别显示保存与离线可用状态。资源失败不撤销已保存笔记，提供重试。离线可用的课件清单同时保存标题、页序和 ID，不依赖在线 API 才能重新打开已有笔记。

### 课堂跟随

在真实网络 fixture 中确认 standard、pro、changjiang 的翻页消息、课件 ID、页 ID 或页序、来源课堂及顺序信息。通过 [browser-lesson-collector.ts](../packages/routing/src/active/browser-lesson-collector.ts) 等现有接入层归一化为新增 `slide.changed` 领域事件，Backend 保存当前页快照，并向 Renderer 提供快照读取和订阅接口。

每种已支持环境都要有独立 fixture。无法可靠识别时显示“当前环境暂不支持跟随”，保留手动浏览；模拟器事件仅用于交互验证，不充当生产协议证据。重复、乱序、跨课堂事件和未知课件页必须有明确过滤规则。重新订阅先读快照并处理订阅期间的竞态，不能必须等待下一次翻页才显示当前位置。

### 导出

导出开始前 flush 笔记，固定本次课件、页面顺序、底图与笔记 revision，避免导出过程中翻页或继续编辑导致内容混用。

- PDF：支持仅标注页，以及附带每页文字笔记的复习版。使用真实页宽高比例，复用隐藏窗口打印机制，等待图片和字体就绪。保持原有无笔记 PDF 导出行为。
- PPTX：底图作为图片放在底层；新增文本框、箭头和矩形映射成可编辑 PPT 对象；bodyText 写入 speaker notes。首版手写与荧光笔可按透明图片导出，保留外观但不承诺逐笔可编辑，并在导出选项中说明。
- 资源缺失：默认指出失败页并中止；用户选择后可用明确占位页继续，不能静默丢页。
- 长笔记、中文字体、荧光笔透明度、不同宽高比和大课件均纳入样例验证。外部软件修改的 PPTX 首版不回写笔记数据库。
- GUI 和 CLI 复用同一导出服务，GUI 通过保存对话框确定路径；CLI 使用显式输出路径。对已存在文件提供明确覆盖处理，取消导出不留下最终的半成品文件。

7. 使用“查看原图”、Esc、Delete、撤销和中文组合输入，不删除底图、不产生隐藏笔画，也不拦截文字输入。
8. 缩窄窗口并依次打开笔记与 AI，画布和工具仍可操作；恢复窗口后不会丢失已折叠面板中的文字。

性能基准采用固定的 100 页课件、当前页 1000 条各含 50 个采样点的笔画样例，记录设备、图片大小和应用版本。目标为已缓存页面切换 p95 小于 200ms、绘制输入反馈 p95 小于 32ms；只挂载当前页画布，缩略图懒加载，完整解码图片数量受控。上述数值是待测目标，不是当前性能承诺。

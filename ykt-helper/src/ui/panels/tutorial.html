雨课堂助手使用教程

工具版本

1.21.3

功能介绍

AI雨课堂助手是一个为雨课堂提供辅助功能的工具，可以帮助你更好地参与课堂互动。

项目仓库：GitHub

脚本安装：GreasyFork

工具栏按钮说明

  • 习题提醒：切换是否在新习题出现时显示通知提示（蓝色=开启）。
  • 课件浏览：查看课件与题目页面，提问可见内容。
  • AI 解答：向 AI 询问当前题目并显示建议答案。
  • 自动作答：切换自动作答（蓝色=开启）。
  • 设置：配置 API 密钥与自动作答参数。
  • 使用教程：显示/隐藏当前教程页面。

自动作答

  • 在设置中开启自动作答并配置延迟/随机延迟。
  • 需要配置 LLM API 密钥。
  • 答案来自 AI，结果仅供参考。

AI 解答

  1. 点击设置（）填入 API Key。
  2. 每个 AI Profile 可单独设置 Temperature（0–2）；留空时使用模型默认值，不会发送该参数。
  3. 点击 AI 解答（）后会对“当前题目/最近遇到的题目”询问并解析。

课堂提醒、手机版与亮屏

  • 设置中可以分别控制新题、题组发布、课件发布、其他发布、下课以及自动作答的每个阶段；系统通知、页面弹窗和提示音也可单独关闭。
  • 打开或翻阅旧课件不会触发课件发布提醒；发布类提醒只提示，不会自动作答或提交。
  • 手机进入 /m/v2 时会使用“仅提醒”模式，点击右下角铃铛即可设置提醒和亮屏，不会启动自动作答。
  • 系统通知需由浏览器或篡改猴授予权限；脚本不会自动请求或修改系统通知权限。
  • “课堂保持亮屏”仅在可见的课堂页防止自动熄屏，无法阻止手动锁屏、后台冻结或系统省电策略。

注意事项

1) 仅供学习参考，请独立思考；

2) 合理使用 API 额度；

3) 答案不保证 100% 正确；

4) 自动作答有一定风险，谨慎开启。
